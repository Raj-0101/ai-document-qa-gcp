# AI Document Q&A on Google Cloud

An AI-powered application that allows users to upload PDF documents and ask questions about them using Vertex AI Gemini.

## Features

- Upload PDF documents
- Store files in Google Cloud Storage
- Ask questions about uploaded documents
- AI-powered answers using Vertex AI Gemini
- Chat history (coming soon)
- Cloud Run deployment (coming soon)

## Tech Stack

- FastAPI
- React
- Google Cloud Storage
- Vertex AI
- Firestore
- Cloud Run
- Docker
